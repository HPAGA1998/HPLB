HPlb v1.7.1

Документация и рабочие примеры

Кнопки, поля ввода и карточки для HTML.

Начните с подключения, выберите компонент в справочнике или найдите пример по названию класса.

В каждом сравнении слева показан HPlb, справа — обычный HTML со стандартным оформлением браузера. На узком экране варианты расположены друг под другом.

Подключение

  1. Разместите hplb.css и hplb.js рядом с HTML-страницей.
  2. Подключите CSS в head.
  3. Разместите карточки до скрипта и подключите hplb.js в самом конце body.
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Пример HPlb</title>
    <link rel="stylesheet" href="hplb.css">
</head>
<body>
    <info-card title="Информация">Добро пожаловать!</info-card>
    <button class="btn btn-accept" type="button">Accept</button>

    <script src="hplb.js"></script>
</body>
</html>

Для кнопок, полей и CSS-классов нужен только hplb.css. Для карточек дополнительно нужен hplb.js. Подключайте скрипт один раз: повторная регистрация Custom Elements вызывает ошибку.

Кнопки

Начните с .btn, затем добавьте размер и один цветовой модификатор. Базовая кнопка имеет padding: 5px, border-radius: 5px, width: max-content и прозрачную рамку 1px. При наведении рамка становится чёрной, курсор — указателем; .btn плавно увеличивается до 105%.

Для ссылок a.btn без классов btn-accept и btn-delete задан светло-серый фон; кнопкам button — нет. Ссылкам также задан display: inline-block.

Цель демонстрационных ссылок.

В CSS записано color: auto, но auto не является допустимым значением color и браузер игнорирует это объявление. Без цветового модификатора ссылку оформляет браузер; .btn-accept и .btn-delete задают цвет текста.

Класс btn выбирается и при дополнительных классах: a.btn подходит для class="btn btn-big". Селектор a[class="btn"] выбрал бы только точное значение btn и не подошёл бы для такой комбинации.

Поля ввода

В этой версии .inp оформляет input с type="text", "number", "password", "email", "url", "tel", "checkbox" или "radio", а также select.inp. Для текстовых полей заданы серая рамка 2px, скругление 5px, высота 25px и размер текста 25px. При фокусе рамка становится чёрной, а поле плавно увеличивается до 105%; :invalid задаёт красную рамку. Checkbox и radio плавно увеличиваются до 130% при наведении.

В этой версии текстовые стили заданы только для type="text", "number", "password", "email", "url" и "tel". В CSS также указано type="name": это несуществующее значение типа input, поэтому правило не описывает корректное поле имени. Для имени используйте type="text".

Валидацию выполняет браузер; HPlb оформляет результат. Кнопки показа пароля и собственного механизма проверки данных в библиотеке нет.

Для checkbox и radio движок задаёт accent-color: green. Вид символа отметки остаётся стандартным для браузера; публичного API для выбора символа нет.

АтрибутНазначениеЕсли отсутствует
bg-clCSS-цвет фона.В шаблон попадает null; браузер отклоняет это значение цвета.
cl-clCSS-цвет левой рамки толщиной 5px.В шаблон попадает null; соответствующее правило рамки недопустимо.
titleЗаголовок внутри h3.Выводится текст null.

Задайте атрибуты до подключения hplb.js. После создания изменения не отслеживаются: observedAttributes и attributeChangedCallback не реализованы.

Особенности и ограничения

  • Преобразование карточки происходит в constructor(). Разместите карточки в исходной разметке до подключения движка.
  • document.createElement() для зарегистрированной карточки вызывает NotSupportedError: конструктор изменяет дочерние узлы. Для текущей реализации используйте декларативную разметку до скрипта.
  • h5 предназначен для фразового содержимого: произвольные блоки, кнопки и поля внутри него не соответствуют модели содержимого HTML.
  • Перезапись innerHTML пересоздаёт дочерние узлы; назначенные прежним узлам обработчики событий не сохраняются.
  • Карточки имеют width: max-content. Длинные строки могут выходить за узкий контейнер.
  • Повторное подключение hplb.js вызывает ошибку повторной регистрации имён.
Вставляйте в карточки только доверенное содержимое. Движок использует innerHTML без очистки. У custom-card, если он есть в версии, заголовок и цвета также вставляются в HTML-шаблон.

JavaScript API

КлассЗарегистрированный элемент
DangerCard<danger-card>
InfoCard<info-card>
CustomCard<custom-card>

Отдельного объекта HPlb, экспортов модулей, публичных методов управления и собственных событий нет. Основной API — CSS-классы, теги карточек и атрибуты custom-card.

Проверить регистрацию можно стандартным API браузера после загрузки движка:

customElements.get("danger-card"); // DangerCard
customElements.get("info-card"); // InfoCard
customElements.get("custom-card"); // CustomCard

Объявления class в обычном скрипте не создают одноимённые свойства window.

hplb.js
// HPlb v1.7.1
//danger-card
class DangerCard extends HTMLElement {
    constructor() {
        super();
        var content = this.innerHTML
        this.innerHTML = `
        <div style="background-color: rgb(255, 97, 97); border-left: 5px solid red; border-radius: 5px; width: max-content; padding-left: 5px; padding-right: 5px; cursor:not-allowed;" class="hover">
            <h3>${this.getAttribute("title")}</h3>
            <h5>${content}</h5>
        </div>
        `
    }
}
customElements.define("danger-card", DangerCard)
//info-card
class InfoCard extends HTMLElement {
    constructor() {
        super();
        var content = this.innerHTML
        this.innerHTML = `
        <div style="background-color: rgb(207, 226, 232); border-left: 5px solid lightblue; border-radius: 5px; width: max-content; padding-left: 5px; padding-right: 5px; cursor:help;" class="hover">
            <h3>${this.getAttribute("title")}</h3>
            <h5>${content}</h5>
        </div>
        `
    }
}
customElements.define("info-card", InfoCard)
//custom-card
class CustomCard extends HTMLElement {
    constructor() {
        super();
        var content = this.innerHTML
        this.innerHTML = `
        <div style="background-color: ${this.getAttribute("bg-cl")}; border-left: 5px solid ${this.getAttribute("cl-cl")}; border-radius: 5px; width: max-content; padding-left: 5px; padding-right: 5px; cursor:pointer;" class="hover">
            <h3>${this.getAttribute("title")}</h3>
            <h5>${content}</h5>
        </div>
        `
    }
}
customElements.define("custom-card", CustomCard)
